# B2B migration backup

Download **B2B-project-and-conversations.zip** and extract it on Windows.

The archive contains 824 project files and 44 recovered local Codex B2B conversation transcripts (2,098 messages), captured on 24 October 2026. Open `project/` to work on the code and `conversations/` to read the discussions. Read the README inside the archive for limitations and setup details.

This is a sanitized public backup. Detected credentials and credential-like literals have been redacted, including some development/test values. Private environment files, database contents, Docker volumes, installed dependencies, build caches, original Git history and internal tool traces are excluded. ChatGPT-only history and attachments outside the project are not included. Markdown transcripts preserve readable context; they do not automatically import as native Codex tasks.

Keep the Linux installation until private configuration and databases have been transferred separately. On Windows, provide the relevant exported transcripts to your assistant to continue with the saved context.
